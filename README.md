# Everyday Conversations — កូដសម្រាប់ Customize

## របៀបប្រើ
1. បើក terminal នៅក្នុង folder គម្រោង ហើយរត់ `python3 -m http.server 8000` បន្ទាប់មកបើក `http://localhost:8000` ក្នុង browser (កុំបើកដោយ `file://` ព្រោះ ES modules ត្រូវការ HTTP server; Chrome ល្អបំផុតសម្រាប់ TTS)
2. ចុច **"▶ លេងស្វ័យប្រវត្តិ"** — នឹងរាប់ថយក្រោយ **3-2-1** ជាមុន (ឲ្យពេលអ្នកចុច record) រួចបន្តលាត + និយាយដោយស្វ័យប្រវត្តិទាំងអស់ (Speaker A = សំឡេងប្រុស, Speaker B = សំឡេងស្រី) — ចុចម្តងទៀតដើម្បីផ្អាក
3. ចុច **⛶** (ជ្រុងខាងលើស្តាំកាត) ដើម្បីចូល Fullscreen — លាក់ browser UI ស្អាតសម្រាប់ថត screen recording
4. អូសគ្រាប់ **"⏱ ល្បឿនរវាងបន្ទាត់"** ដើម្បីកំណត់រយៈពេលរង់ចាំរវាងបន្ទាត់នីមួយៗក្នុង Auto-play (0.2s = លឿនបំផុត, 3s = យឺតបំផុត) — មានប្រយោជន៍សម្រាប់សិស្សដែលចង់ពេលគិត/ធ្វើតាមច្រើន/តិច
5. ចុច **🎨** (ជ្រុងខាងលើកាត) ដើម្បីបើកផ្ទាំង Customize — ប្តូរពណ៌ ឬដាក់រូបភាពផ្ទៃខាងក្រោយផ្ទាល់ខ្លួន
6. ចុច "លាតបន្ទាត់បន្ទាប់ →" ដើម្បីលាតដោយដៃម្តងមួយៗ (មានអានផងបើ "អានពេលចុចដៃ" បើក)
7. ចុច 🔊 ក្បែរប្រយោគណាមួយ ដើម្បីអានឡើងវិញតែម្នាក់ឯង
8. ចុច "ត្រឡប់ ←" ដើម្បីត្រឡប់ក្រោយ
6. ចុច "ឆាកបន្ទាប់ ⇥" ដើម្បីរំលងទៅឆាកបន្ទាប់ភ្លាមៗ

> គន្លឹះ: បើអ្នកចង់ថតសំឡេងផ្ទាល់ខ្លួន (មិនប្រើ AI voice) សូមចុចបិទ "អានពេលចុចដៃ" ជាមុនសិន រួចប្រើ 🔊 ត្រង់ប្រយោគជា script មើលមុនពេលថត។

## របៀប Customize ការសន្ទនា
បើក `index.html` ដោយ text editor (VS Code ជាដើម) រកមើល array `scenes` (ប្រហែលជួរទី ១៦០):

```js
const scenes = [
  {
    topic: "At a Coffee Shop",
    lines: [
      { speaker: "A", en: "Hi! What would you like to order?", km: "សួស្តី! តើអ្នកចង់បញ្ជាទិញអ្វី?" },
      { speaker: "B", en: "Can I get a small latte, please?", km: "សុំកាហ្វេឡាតេមួយកែវតូចបានទេ?" },
      // ... បន្ថែម/កែប្រែបន្ទាត់ថែមទៀត
    ]
  },
  // ... បន្ថែម scene ថ្មីទាំងមូលនៅទីនេះ
];
```

- `topic` = ចំណងជើងឆាក (បង្ហាញនៅផ្នែកខាងលើកាត)
- `speaker` = `"A"` ឬ `"B"` (កំណត់ថាបែបលក្ខណៈណាមួយបង្ហាញនៅឆ្វេង/ស្តាំ និងពណ៌ avatar)
- `en` = ប្រយោគអង់គ្លេស
- `km` = ន័យខ្មែរ

## របៀបប្តូរសំឡេង TTS (ប្រុស/ស្រី)
ក្នុងអនុគមន៍ `speak()`:
```js
utter.lang = 'en-US';   // ប្តូរទៅ 'en-GB' សម្រាប់សំឡេងអង់គ្លេស
utter.rate = 0.9;       // ល្បឿននិយាយ (0.1–2, តូចជាង = យឺតជាង)
```
Speaker `"A"` = សំឡេងប្រុស, Speaker `"B"` = សំឡេងស្រី។ អនុគមន៍ `pickVoice()` ព្យាយាមរកសំឡេងប្រុស/ស្រីពិតប្រាកដតាមឈ្មោះ voice ដែល browser មាន (ឧ. David/Zira/Samantha) បើរកមិនឃើញ វានឹងប្តូរ `pitch` (0.85 សម្រាប់ប្រុស, 1.2 សម្រាប់ស្រី) ដើម្បីអោយស្តាប់ខុសគ្នាដដែល។ Voice ដែលមាននឹងខុសគ្នាទៅតាម browser/OS របស់អ្នក។

`autoSpeak` (default `true`) កំណត់ថាតើប្រយោគនីមួយៗអានពេលចុចដៃលាតដោយខ្លួនឯង។ ចំណែក **Auto-play** ជាមុខងារឯករាជ្យ — ចុចម្តងវានឹងបន្តលាត+និយាយរហូតដល់ចប់ scenes ទាំងអស់ដោយស្វ័យប្រវត្តិ (មិនចាំបាច់ចុចដៃឡើយ)។

## របៀបផ្លាស់ប្តូររូបរាង (Design)
ពណ៌សំខាន់ៗនៅផ្នែក `:root { ... }` ក្នុង CSS:
- `--gold`, `--jade`, `--lac` = ពណ៌សំខាន់ៗ
- `--a-bg`, `--b-bg` = ពណ៌ bubble របស់ speaker A និង B

## គំនិតបន្ថែម
- បន្ថែម speaker ទីបី (C) បើមានការសន្ទនាច្រើននាក់ — ត្រូវបន្ថែម CSS class `.speaker-c` ថ្មី
- ប្តូរ avatar ពីអក្សរ (A/B) ទៅជារូបភាព profile photo ដោយប្តូរ `<div class="avatar">A</div>` ទៅ `<img src="...">`
- ថតវីដេអូ: បើក index.html → screen record (OBS Studio, QuickTime) → និយាយសំឡេងផ្ទាល់ខ្លួនស្របតាមចង្វាក់ click ចុច button

## ភ្លេងផ្ទៃខាងក្រោយ (Background Music)
1. ចុច "ជ្រើសរើសឯកសារ" ក្រោម "🎵 ភ្លេងផ្ទៃខាងក្រោយ" ជ្រើសរើសឯកសារ MP3/WAV ពីកុំព្យូទ័រអ្នក
2. ចុច "▶ ចាក់ភ្លេង" ដើម្បីចាប់ផ្តើម — អាចកែកម្រិតសំឡេងតូច/ធំដោយអូសគ្រាប់ volume (default 15% ល្មមសម្រាប់ភ្លេងផ្ទៃខាងក្រោយ)
3. បើចុច "▶ លេងស្វ័យប្រវត្តិ" ភ្លេងនឹងចាប់ផ្តើម **fade in** ចាក់ជាមួយគ្នាដោយស្វ័យប្រវត្តិ (បើអ្នកបានផ្ទុកឯកសារភ្លេងរួច) ហើយវានឹង **fade down** បន្តិចរវាង scene ដើម្បីកុំឲ្យខាំសំឡេងអាន រួច fade ឡើងវិញនៅ scene ថ្មី

**សំខាន់**៖ ភ្លេងនេះចាក់តែក្នុង browser ប៉ុណ្ណោះ — កូដនេះមិនផ្សំសំឡេង TTS + ភ្លេង ចូលទៅជា file វីដេអូតែមួយដោយស្វ័យប្រវត្តិទេ។ ដើម្បីបានវីដេអូចេញមកមានទាំងសំឡេងអាន + ភ្លេង៖
- ប្រើ **screen recording** (OBS Studio, QuickTime) ថតអេក្រង់ ព្រមទាំងជ្រើសរើស "record system audio / computer sound" — វានឹងចាប់ទាំងសំឡេង TTS និងភ្លេងក្នុងពេលតែមួយ

## ការប្តូរពណ៌ និងផ្ទៃខាងក្រោយ (Theme Customization)
ចុច 🎨 នៅជ្រុងខាងលើកាត នឹងបើកផ្ទាំងដែលមាន៖
- **Color picker ៧** សម្រាប់ពណ៌សំខាន់ៗ (Accent, Speaker B, សំឡេងកំពុងលេង, ផ្ទៃខាងក្រោយទំព័រ/កាត, ពពុះនិយាយ A/B) — ប្តូរបានភ្លាមៗ គ្មានចាំបាច់កែកូដ
- **រូបភាពផ្ទៃខាងក្រោយ**: ជ្រើសរើសរូបភាពពីកុំព្យូទ័រ — វានឹងដាក់ជាផ្ទៃខាងក្រោយ (មាន overlay ស្រាល ដើម្បីអោយអត្ថបទនៅតែអានច្បាស់) ចុច "✕ លុបរូបភាព" ដើម្បីត្រឡប់ទៅផ្ទៃខាងក្រោយធម្មតា
- **↺ ត្រឡប់ពណ៌លំនាំដើម**: កែពណ៌ទាំងអស់ត្រឡប់ដូចដើម និងលុបរូបភាព

ការកែពណ៌ទាំងនេះជាការផ្លាស់ប្តូរស្ថិតក្នុង browser session ប៉ុណ្ណោះ (មិនរក្សាទុកស្វ័យប្រវត្តិទេ) — បើចង់ឲ្យពណ៌ថ្មីនៅជាប់អចិន្ត្រៃយ៍ ត្រូវកែតម្លៃ default ក្នុងកូដ CSS `:root{ ... }` ដោយផ្ទាល់។

## Tech ដែលបានប្រើ
- HTML/CSS/JS សុទ្ធ (គ្មាន framework, គ្មាន build step)
- Web Speech API (`SpeechSynthesisUtterance`) — built-in browser TTS ឥតគិតថ្លៃ, គ្មាន API key
- Fonts: Noto Serif/Sans Khmer, Fraunces, Inter (ពី Google Fonts)

## Clean Recording Mode

សម្រាប់ថត screen recording សូមកំណត់ចំនួនវិនាទីក្នុង **ពេលរង់ចាំ** រួចចុច **ចាប់ផ្តើមថតវីដេអូ**។ កម្មវិធីនឹងបិទ header, gamification, settings និង floating controls ដោយស្វ័យប្រវត្តិ ហើយពង្រីក conversation canvas ឲ្យប្រយោគអង់គ្លេស និងការបកប្រែខ្មែរមើលឃើញច្បាស់។ ពេលចេញពី fullscreen UI ដើមនឹងត្រឡប់មកវិញ។
